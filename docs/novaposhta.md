# Нова Пошта: відправник

Ім'я відправника для інтернет-документа — **ФОП Барабан Л.В.**

У `NPTTNSettings` немає поля для назви відправника, тому data-міграція його не записує і схему моделі не розширює. Нова Пошта підставляє відправника з кабінету (Counterparty Sender): тип `Organization`, телефон і Ref. Назва контрагента в кабінеті НП має бути «ФОП Барабан Л.В.».

Телефон відправника, тип, платник доставки і режим післяплати («Контроль оплати», не грошовий переказ) задає міграція `shipping.0003_client_np_defaults`. Вагу за замовчуванням вона не змінює. Автостворення ТТН лишається вимкненим. Типова точка відправки — «Київ №129».
