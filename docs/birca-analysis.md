## 2. Розмітка — блок за блоком

### 2.1 Top bar (промо-банер)
- Тонка смужка зверху із текстом акції/оголошення
- Посилання на деталі
- **У нас:** вже реалізовано через `promo-banner` в `base.html`

### 2.2 Header
- **Фіксований** у верхній частині сторінки
- Темний фон (у birca — темно-зелений/оливковий)
- Елементи зліва направо: бургер-меню (моб) → лого → пошук → телефони (desktop) → кошик
- Під хедером — горизонтальне навігаційне меню з категоріями (desktop)
- **У нас:** структура header повністю аналогічна, різниця лише у кольорі

### 2.3 Breadcrumbs
- Простий текстовий ланцюжок: Головна › Категорія › Підкатегорія › Товар
- Дрібний шрифт (~13px), приглушений колір
- **У нас:** реалізовано inline в `product_detail.html`

### 2.4 Блок товару (product-detail) — ГОЛОВНИЙ

**Layout (desktop):** 2-колонковий flex/grid
- Ліва колонка (~50-55%): галерея
- Права колонка (~45-50%): інформація

**Layout (mobile):** одна колонка, галерея зверху, інфо знизу

#### 2.4.1 Галерея (ліва колонка)
| Елемент | Birca | У нас |
|---------|-------|-------|
| Головне зображення | Великий контейнер, aspect-ratio ~1:1, object-fit contain | Аналогічно |
| Мініатюри (thumbs) | Горизонтальний ряд під основним фото, ~7 шт, scroll | Аналогічно |
| Стрілки | Кнопки вперед/назад поверх зображення | Аналогічно |
| Бейджі | Зверху-зліва (Акція/Топ/Новинка) | Аналогічно |

#### 2.4.2 Інформація (права колонка)
| Елемент | Birca | У нас | Різниця |
|---------|-------|-------|---------|
| Статус | "В наявності" зеленим кольором | Є | — |
| Артикул | "Код: CVE20U" дрібним текстом | Є | — |
| Назва | H1, великий шрифт | Є | — |
| Ціна | Великий жирний текст, виділений кольором | Є | — |
| Кнопка "Купити" | Зелена, на всю ширину | Є | — |
| Купити в 1 клік | Текстове посилання під кнопкою | Є | — |
| Телефони | Список телефонів з іконками | Є | — |
| **Графік роботи** | Таблиця з днями/годинами | **Немає** | **Додати** |
| **Умови повернення** | Розгорнутий блок з текстом | **Немає** | **Додати** |
| **Контактна особа** | Ім'я менеджера | **Немає** | **Опціонально** |

### 2.5 Таби (під товаром)
| Таб | Birca | У нас |
|-----|-------|-------|
| Опис | Текст з форматуванням | Є |
| Характеристики | Таблиця key-value | Є |
| Інфо для замовлення | Текст про доставку/оплату/повернення | Є |
| Відгуки | — | Є (htmx lazy-load) |

### 2.6 Footer
- 4-колонковий grid (desktop), 1-колонка (mobile)
- Блоки: Контакти, Інформація, Покупцям, Графік + соцмережі
- Нижня смужка: копірайт + політика
- **У нас:** повністю аналогічна структура

## 6. Рекомендації для максимальної схожості

### Що НЕ треба міняти (вже добре)
Загальна архітектура сторінки, layout, компонентна структура, CSS-змінні, responsive breakpoints — все це вже відповідає структурі birca або навіть краще (BEM-іменування, CSS custom properties, htmx).

### Що варто додати

1. **`SiteSettings` модель** — додати поля:
   - `work_schedule_table` (JSON або текст із днями/годинами)
   - `return_policy_text` (текст умов повернення)
   - `manager_name` (ім'я контактної особи)

2. **Блок графіку роботи** в `product_detail.html`:
   ```html
   <div class="product-info__schedule">
       <div class="schedule-title">Графік роботи</div>
       <table class="schedule-table">...</table>
   </div>
   ```

3. **Блок умов повернення** в `product_detail.html`:
   ```html
   <details class="product-info__return-policy">
       <summary>Умови повернення та обміну</summary>
       <div class="return-policy__content">...</div>
   </details>
   ```

4. **Горизонтальне меню категорій** (desktop-only):
   ```html
   <nav class="category-nav">
       <div class="container">
           <a href="..." class="category-nav__link">Категорія 1</a>
           ...
       </div>
   </nav>
   ```

### Порядок дій
1. Додати графік роботи + умови повернення у `product-info`
2. Додати горизонтальне меню категорій під хедером (desktop)
3. Стилі для нових компонентів у `product.css` + `header.css`
4. Оновити `SiteSettings` модель + контекст
